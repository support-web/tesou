# 手相鑑定サイト

静的な手相鑑定ランディングページです。`index.html` と `styles.css`、`assets/` 内の画像のみで構成されています。

## 確認方法
静的サイトのためビルドは不要です。以下のいずれかの方法で表示できます。

1. **ファイルを直接開く**
   - ファイルブラウザで `index.html` をダブルクリックするか、ブラウザの「ファイルを開く」で `index.html` を選択します。

2. **ローカルサーバーで確認する（推奨）**
   - リポジトリのルートで以下を実行し、ブラウザで `http://localhost:8000` を開きます。
   - Python 3: `python3 -m http.server 8000`
   - Node.js: `npx serve .`

## 構成
- `index.html`: ページ本体
- `styles.css`: スタイルシート
- `assets/`: 画像アセット

## 開発メモ
HTML/CSSのみの静的構成です。追加のビルド・依存関係はありません。
